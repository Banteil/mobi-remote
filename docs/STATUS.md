# 진행 현황 (2026-10-21 밤 기준)

2026-10-21 슬롯 1 캐릭터로 요일 던전 → 은동전(사냥터+검은 구멍, 룬다 3회) → 공물 → 일일 미션(연금술 포함)까지
봇으로 모두 성공했습니다 (중간에 버그를 고치며 재실행).
중단 키는 F12 (누르면 경고음, 5초 안에 안 멈추면 강제 종료).

## 숙제 흐름
`run.py` 는 `profile.json` 의 슬롯마다 접속한 뒤 `[run].order` 순서로 숙제를 실행합니다.

| 순서 | 태스크 id | 내용 | 실제 확인 |
|---|---|---|---|
| 0 | login | 캐릭터 선택 화면에서 슬롯 카드 선택 후 접속 | 6슬롯 모두 확인 |
| 1 | weekday_dungeon | J → 아르바이트 탭 → 요일 던전 '이동' → 입장 → 추가 루팅 3회 | 단계별로 수동 확인, 한 번에 끝까지는 아직 |
| 2 | silver | 은동전 20개 단위로 사냥터/던전 | 아래 참고 |
| 3 | tribute | 고난도 심층 공략 퀘스트 → 심층 던전(매우 어려움) | 실기 확인 |
| 4 | black_hole | `/` 가이드 → 검은 구멍 바로 가기 → 클리어까지 대기 | 사냥터 안에서 확인 |
| 5 | daily_mission | N → 선물 받기 → 음식·연금술 미션 → 2/4/6회 누적 보상 | 받기·누적 보상 확인, 음식·연금술은 수동으로만 |

### 은동전 (silver)
- 1단위(20개)뿐이면 던전 1회, 2단위 이상이면 사냥터 `field_runs` 회 + 나머지 던전.
- 캐릭터별로 `[silver.by_slot.N]` 로 바꿀 수 있습니다 (던전만 / 사냥터만 / 사냥터 장소 / 던전 종류·층·구역·난이도).
  화면의 캐릭터 탭 카드의 설정 창이 이 표를 고칩니다 (공통 설정과 다른 값만 남김).
- 입장 버튼 가격을 OCR 로 확인해서 20(소탕 10 + 더블 루팅 10)이 아니면 들어가지 않습니다.
  가격 숫자는 Windows OCR, '입장하기'·'임무 시작' 글자는 RapidOCR 과 Windows OCR 중 하나라도 맞으면 됩니다 (docs/PLAN.md 'OCR 규칙').
- 확인 결과:
  - 피오드 던전 1-3, 룬다 던전 1-3: 지도 이동부터 클리어 정리까지 봇이 혼자 성공.
  - 창백한 산 사냥터: 입장 성공, 클리어 화면 정리 성공.
  - **사냥터 → 검은 구멍 → 사냥터 클리어 대기 → 던전** 전체를 한 번에 돈 적은 아직 없음.

### 사냥터 안 검은 구멍
- 검은 구멍은 사냥터 안에 30분마다 3개 나오고, 다 깨면 30분 동안 못 들어갑니다. 그래서 하루 1회만 갑니다.
- 은동전 사냥터에 들어가면 (`[silver] black_hole_in_field = true`) 검은 구멍부터 처리하고,
  끝나면 사냥터 임무가 자동으로 이어집니다. 성공하면 뒤쪽 `black_hole` 태스크는 "이미 완료"로 건너뜁니다.
- 사냥터 안 검은 구멍이 실패하면 사냥터는 그대로 진행하고 `black_hole` 태스크에서 다시 시도합니다.
- 캐릭터 탭에서 검은 구멍을 끈 캐릭터는 `[run.skip_by_slot]` 로 `black_hole` 태스크를 빼고,
  `black_hole_in_field = false` 로 사냥터 안 검은 구멍도 하지 않습니다.

### 일일 미션
- 미션 종류는 날마다 다르며, 목록과 진행 상태는 CLI `get_daily_missions` 로 읽습니다.
- 음식 N개 먹기: 배고프지 않으면 B 로 못 먹으므로 미션 '진행하기' → 음식 탭 → 여행자 간식 → 사용하기(Space).
- 연금술 3회: '진행하기' → 보석 연금술 → 재료 자동 넣기 → **모두 승급 1회만** → ESC 로 미션 창 복귀.
  승급 직후 다음 단계 '모두 승급'(훨씬 비쌈)이 바로 뜨므로 두 번 누르면 안 됩니다.
- 그 외 미완료 미션은 결과 요약에 남깁니다.

## 어비스 반복 (`mabi/tasks/abyss.py`, 리모콘 '어비스' 탭)
- ESC 메뉴 → 어비스 → 던전(기본 '허상의 정박지') → 함께하기 → 난이도(기본 매우 어려움2) → 우연한 만남 켜기 → 입장하기.
- 판 진행은 게임 숏컷이 알아서 함. 끝은 CLI `IsAbyssResultSequencePlaying`, 사망은 `IsDead` 로 판단.
  사망하면 우상단 나가기로 나와 처음부터 다시 입장. 판 중에도 배고프면 B.
- 끝나면 화면 터치 → 보상 화면에서 다시 하기(Space). 기본은 F12 까지 무한, 판 수·분 제한 가능.
- 입장 뒤에는 **백그라운드**: 화면은 PrintWindow, 키는 PostMessage(포커스 메시지로 감싸서).
  클릭은 PostMessage 가 안 먹으므로 잠깐 앞으로 가져와 누르고 원래 창으로 돌려준다.
  뒤에서 키를 보낸 뒤 다시 앞으로 가져올 땐 작업 표시줄을 한 번 거쳐야 SendInput 이 먹는다 (`Bot.ensure_focus`).
- 사람이 옆에서 다른 일을 하므로 '게임 조작 감지 일시정지'는 쓰지 않는다.
- 캐릭터를 고르면 `login.run` 으로 바꾼 뒤 시작 (실기 미확인).
- 어디서 시작해도 그 자리부터 (`abyss.where`): 어비스 안 · 클리어/보상 화면 · 매칭 중 · 입장 화면 · 어비스 목록 · 메뉴(ESC) ·
  메인 · 로딩 · 그 밖의 창(ESC 로 닫음). 입장 화면·목록·메뉴는 2026-10-24 실기로 판정 확인.
  매칭 중 화면은 아직 못 봐서 '입장 화면인데 입장하기·이동하기 버튼이 없음' 으로 본다.
  캐릭터를 지정한 카드는 이름을 메인 화면에서만 읽을 수 있어, 입장 화면·목록이면 한 번 닫고 확인한 뒤 다시 연다.

## 게임 동작 메모
- 6시 이후 첫 접속 때는 메인 화면 전에 출석 이벤트 대화, '오늘의 스텔라 픽', 공지 웹 팝업이 나올 수 있습니다.
  `login.settle_first_login` 이 순서와 상관없이 처리합니다 (대화 넘기기 / 가운데 카드 → 스텔라 픽 / ESC).
  출석 이벤트 대화의 넘기기 버튼이 기존 '대화 넘기기' 템플릿과 같은지는 아직 확인하지 못했습니다.
- 채팅 입력창이 열려 있으면 HUD 의 키 안내(ESC 등)가 사라져 메인 화면 인식이 실패합니다.
- 하루 초기화는 오전 6시. 6시 전은 전날로 칩니다 (`state/<날짜>.json`).
- 접속 전환을 너무 자주 하면 "인증 오류" → 접속 사이 최소 60초.
- ASSIST(H, 우하단 자동 스킬)는 켜져 있어야 하고 봇은 건드리지 않습니다.
- 검은 구멍은 입장 즉시 횟수가 차감되므로 도중에 나가면 안 됩니다.
- 추가 루팅은 요일 던전에만 있고 3회 모두 합니다 (골드 6천/1만2천/1만8천).
- 클리어 후 NPC 대화는 모험가 길드 주간 정기 의뢰 조건(심층 3회 / 일반 5회 / 사냥터 5회)을 채웠을 때만 나옵니다.
  봇은 대화가 있으면 넘기고, 없으면 그냥 지나갑니다.
- 사냥터 클리어 화면에서는 CLI 퀘스트 목록이 비어서 나옵니다. 사냥 퀘스트가 3번 연속(약 15초) 없어야 클리어로 봅니다.
- CLI `get_activity` 는 로딩 중 오류를 내고, 지역 이동 중에는 `IsAutoTraveling` 이 false 가 됩니다.
  도착은 장소 이름이나 템플릿으로 판단합니다.
- 캐릭터 선택 화면 카드: 선택된 카드는 노란 테두리·금색 배경에 얼굴 확대 그림. 카드 아래 이름 → 접속 시간 → (대표 캐릭터) → 재화 순.
  스크롤 맨 아래에서 마지막 줄이 화면 아래 어두운 띠에 걸리면 이름 글자가 회색이 된다.
- `bot.to_main()` 은 배고픔 표시가 보이면 음식을 하나 먹는다 (B). 캐릭터 자동 설정으로 선택 화면에 나갈 때도 일어난다.
- CLI `get_my_info` 에는 캐릭터 이름이 없다 (Title = 착용 타이틀, RealmName = 서버).
- 봇은 화면을 캡처해서 인식하므로 다른 창이나 Windows 알림이 게임을 덮으면 실패합니다.
  캡처 전에 게임 창을 앞으로 가져오지만, 알림은 그래도 위에 뜨므로 **방해 금지 모드**를 켜 두세요.

## 작업 큐 (`mabi/workqueue.py`, `gui_app/queue_api.py`)
- 큐의 주인은 파이썬. 화면(web/queue.js)은 'mm:queue' 상태를 그리고 버튼만 보낸다 → 화면을 다시 띄워도 큐는 안 끊김
- 카드 종류: daily(일일 숙제) · abyss(어비스 반복) · goal(제작·채집·가공 목표) · action(버튼 하나 = 명령 하나, 전체 수령)
- 파란 버튼 = 지금 바로 (맨 위에 넣고 돌던 것은 대기로 밀었다가 이어서), '목표' = 맨 아래에 담기
- 일시정지 = 돌던 동작을 잠깐 멈춤. 맨 위 한 장만, 큐는 일시정지 카드에서 선다, 껐다 켜면 대기로 (하던 자리 기록은 유지)
- F12 하나로 전체: 돌고 있으면 무엇이든 일시정지(지금 명령도 끊음 — 날개가 들어도 멈춤 우선), 쉬고 있으면 맨 위 일시정지 카드 이어 하기
- 화면 설정 맞추기는 큐 한 번에 한 번, 할 일이 다 끝나면 되돌림
- 목표 카드가 사람에게 물어야 하면(재료를 직접 구해 와야 함) 'mm:queue-ask' → queue.answer
