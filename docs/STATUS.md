# 진행 현황 (2026-10-21 밤 기준)

2026-10-21 슬롯 1 캐릭터로 요일 던전 → 은동전(사냥터+검은 구멍, 룬다 3회) → 공물 → 일일 미션(연금술 포함)까지
봇으로 모두 성공했습니다 (중간에 버그를 고치며 재실행).
중단 키는 F12 (누르면 경고음, 5초 안에 안 멈추면 강제 종료).

## 숙제 흐름
`run.py` 는 `profile.json` 의 슬롯마다 접속한 뒤 `[run].order` 순서로 숙제를 실행합니다.

| 순서 | 태스크 id | 내용 | 실제 확인 |
|---|---|---|---|
| 0 | login | 캐릭터 선택 화면에서 슬롯 카드 선택 후 접속 | 6슬롯 모두 확인 |
| 1 | weekday_dungeon | J → 아르바이트 탭 → 요일 던전 '이동' → 입장 → 추가 루팅 3회 | 단계별로 수동 확인, 한 번에 끝까지는 아직 |
| 2 | silver | 은동전 20개 단위로 사냥터/던전 | 아래 참고 |
| 3 | tribute | 고난도 심층 공략 퀘스트 → 심층 던전(매우 어려움) | 실기 확인 |
| 4 | black_hole | `/` 가이드 → 검은 구멍 바로 가기 → 클리어까지 대기 | 사냥터 안에서 확인 |
| 5 | daily_mission | N → 선물 받기 → 음식·연금술 미션 → 2/4/6회 누적 보상 | 받기·누적 보상 확인, 음식·연금술은 수동으로만 |

### 은동전 (silver)
- 1단위(20개)뿐이면 던전 1회, 2단위 이상이면 사냥터 `field_runs` 회 + 나머지 던전.
- 캐릭터별로 `[silver.by_slot.N]` 로 바꿀 수 있습니다 (던전만 / 사냥터만 / 사냥터 장소 / 던전 종류·층·구역·난이도).
  화면의 캐릭터 탭 카드의 설정 창이 이 표를 고칩니다 (공통 설정과 다른 값만 남김).
- 입장 버튼 가격을 OCR 로 확인해서 20(소탕 10 + 더블 루팅 10)이 아니면 들어가지 않습니다.
  가격 숫자는 Windows OCR, '입장하기'·'임무 시작' 글자는 RapidOCR 과 Windows OCR 중 하나라도 맞으면 됩니다 (docs/PLAN.md 'OCR 규칙').
- 확인 결과:
  - 피오드 던전 1-3, 룬다 던전 1-3: 지도 이동부터 클리어 정리까지 봇이 혼자 성공.
  - 창백한 산 사냥터: 입장 성공, 클리어 화면 정리 성공.
  - **사냥터 → 검은 구멍 → 사냥터 클리어 대기 → 던전** 전체를 한 번에 돈 적은 아직 없음.

### 사냥터 안 검은 구멍
- 검은 구멍은 사냥터 안에 30분마다 3개 나오고, 다 깨면 30분 동안 못 들어갑니다. 그래서 하루 1회만 갑니다.
- 은동전 사냥터에 들어가면 (`[silver] black_hole_in_field = true`) 검은 구멍부터 처리하고,
  끝나면 사냥터 임무가 자동으로 이어집니다. 성공하면 뒤쪽 `black_hole` 태스크는 "이미 완료"로 건너뜁니다.
- 사냥터 안 검은 구멍이 실패하면 사냥터는 그대로 진행하고 `black_hole` 태스크에서 다시 시도합니다.
- 캐릭터 탭에서 검은 구멍을 끈 캐릭터는 `[run.skip_by_slot]` 로 `black_hole` 태스크를 빼고,
  `black_hole_in_field = false` 로 사냥터 안 검은 구멍도 하지 않습니다.

### 일일 미션
- 미션 종류는 날마다 다르며, 목록과 진행 상태는 CLI `get_daily_missions` 로 읽습니다.
- 음식 N개 먹기: 배고프지 않으면 B 로 못 먹으므로 미션 '진행하기' → 음식 탭 → 여행자 간식 → 사용하기(Space).
- 연금술 3회: '진행하기' → 보석 연금술 → 재료 자동 넣기 → **모두 승급 1회만** → ESC 로 미션 창 복귀.
  승급 직후 다음 단계 '모두 승급'(훨씬 비쌈)이 바로 뜨므로 두 번 누르면 안 됩니다.
- 그 외 미완료 미션은 결과 요약에 남깁니다.
- 선물 받기: CLI 가 '다 했는데 선물 안 받음'이라는 미션이 없어질 때까지 목록을 맨 위부터 휠 3칸씩 내려가며
  '선물 받기'를 하나씩 누르고, 받아졌는지는 패킷(받기 성공) → CLI 로 본다. 예전엔 10칸씩 크게 내려 가운데 줄을
  건너뛰어 11개 중 4개만 받았다 (2026-10-25). 연금술·채집 완료도 패킷 '미션 완료' 알림으로 바로 안다.
  남으면 창을 새로 열어 다시 훑는다 (새로 열면 받을 카드가 맨 위로 모인다. 연금술에서 ESC 로 돌아온 창에서 맨 윗줄 2개를
  못 찾은 적이 있다). 버튼은 창이 열리는 연출 중 점수가 0.74 까지 떨어져 한 장만 보고 없다고 하지 않는다.
  그래도 남으면 미션 창 스크린샷(dm_missed)을 남긴다.
- 캐릭터 숙제가 다 끝난 뒤 받을 선물이 있으면 (일일 미션 뒤 아르바이트 → '따뜻한 손길' 등) CLI 로 보고 그것만 받는다.

## 어비스 반복 (`mabi/tasks/abyss.py`, 리모콘 '어비스' 탭)
- ESC 메뉴 → 어비스 → 던전(기본 '허상의 정박지') → 함께하기 → 난이도(기본 매우 어려움2) → 우연한 만남 켜기 → 입장하기.
- 판 진행은 게임 숏컷이 알아서 함. 끝은 CLI `IsAbyssResultSequencePlaying`, 사망은 `IsDead` 로 판단.
  사망하면 우상단 나가기로 나와 처음부터 다시 입장. 판 중에도 배고프면 B.
- 끝나면 화면 터치 → 보상 화면에서 다시 하기(Space). 기본은 F12 까지 무한, 판 수·분 제한 가능.
- 입장 뒤에는 **백그라운드**: 화면은 PrintWindow, 키는 PostMessage(포커스 메시지로 감싸서).
  클릭은 PostMessage 가 안 먹으므로 잠깐 앞으로 가져와 누르고 원래 창으로 돌려준다.
  뒤에서 키를 보낸 뒤 다시 앞으로 가져올 땐 작업 표시줄을 한 번 거쳐야 SendInput 이 먹는다 (`Bot.ensure_focus`).
- 사람이 옆에서 다른 일을 하므로 '게임 조작 감지 일시정지'는 쓰지 않는다.
- 캐릭터를 고르면 `login.run` 으로 바꾼 뒤 시작 (실기 미확인).
- 어디서 시작해도 그 자리부터 (`abyss.where`): 어비스 안 · 클리어/보상 화면 · 매칭 중 · 입장 화면 · 어비스 목록 · 메뉴(ESC) ·
  메인 · 로딩 · 그 밖의 창(ESC 로 닫음). 입장 화면·목록·메뉴는 2026-10-24 실기로 판정 확인.
  매칭 중 화면은 아직 못 봐서 '입장 화면인데 입장하기·이동하기 버튼이 없음' 으로 본다.
  캐릭터를 지정한 카드는 이름을 메인 화면에서만 읽을 수 있어, 입장 화면·목록이면 한 번 닫고 확인한 뒤 다시 연다.
- **장비 수리** (`mabi/tasks/repair.py`): 판이 끝났을 때 장비 내구도가 `[abyss] repair_below`(기본 0.05 = 5%) 이하면
  '다시 하기' 대신 나가서 퀵 내비게이터('.' 키, `[game] quick_nav_key`) → 대장간(빠른 이동 T) → 대화가 저절로 열림
  → '수리' 버튼이 보일 때까지 대사 넘기기 → 수리 → 전체 수리(Space) → 수리하기(Space) → 대화 종료 → 다시 입장.
  수리 동안은 게임을 앞에 둔다. 2026-10-25 실기 확인 (내구도 98% · 기준 100% 로 시험).
  - 내구도는 패킷 '장비 내구도 깎임' 알림(현재/최대 비율)으로만 안다 (CLI 에 없음). 장비 번호가 없어 수리 뒤로 본 가장 낮은 값을 쓴다.
    리모콘을 켠 뒤 한 번도 안 깎였으면 모름 → 수리하지 않음. 수리 성공은 패킷으로 확인.
  - 고칠 장비가 없으면 '수리' 버튼이 꺼져 눌러도 아무 일이 없다 (패킷의 대사 단계가 그대로) → 그대로 나온다.
  - 수리했는데 다음 판 내구도가 수리 전보다 높아지지 않았으면 카드 실패.

## NPC 대화 (`mabi/tasks/dialogue.py`) · 화면 글자 (`mabi/tasks/ui_text.py`)
- 아르바이트·요일 던전·대장간이 같이 쓰는 대화 처리. 패킷(대화 중 · 대사 단계 · 선택지 메뉴)으로 먼저 보고, 없으면 화면.
- 대사는 몇 마디일지 NPC·때마다 달라서 대사 내용·종류로 판단하지 않는다. 대화 중이고 메뉴 버튼이 안 보이면
  '대화 넘기기' 자리를 누르고, 누를 때마다 패킷의 대사 단계가 넘어갔는지 본다.
- 패킷의 '메뉴' 는 첫 대사와 같은 순간에 오지만 화면 버튼은 대사를 넘긴 뒤 뜬다 → 메뉴 = 패킷 메뉴 + '대화 넘기기' 안 보임.
- 루틴만의 조작은 `talk`·`leave` 에 처리기(handlers)로 넘긴다 (예: 대장간 수리 창 ESC).

## 상태 판단 순서 (`mabi/bot.py`)
- 패킷 → CLI → 화면 순으로 본다. 화면 그림은 누를 자리를 찾을 때와, 패킷·CLI 가 모를 때만 판단에 쓴다.
- 넘기기 버튼(`Bot.skip_button`): '대화 넘기기'·'장면 넘기기' 는 같은 자리에 같은 글자라 그림만으로는 헷갈린다
  (2026-10-25 보스 출현 연출을 대화로 알아보고 눌러 게임이 앞으로 튀어나옴). 종류는 패킷 컷신·대화 중 → CLI 대화 중 → 그림 점수 순.
- 어비스·던전 중(`Bot.scene_skip` 꺼짐)이나 뒤에서 도는 중엔 연출을 누르지 않고 스스로 끝나길 기다린다.
- 어비스 안(`abyss.inside`)·결과 화면(`after_clear`)은 패킷 맵 종류·결과로, '다시 하기' 눌림은 패킷 매칭 상태로,
  게임 시작 눌림은 패킷 게임 입장으로, 장소 이름(`content.game_space`)은 패킷 맵 이름으로 먼저 본다.
- 메인 화면(`at_main`)은 패킷이 로딩 중·캐릭터 선택이면 아니다. 창이 하나도 안 열렸는지는 패킷에 없어 HUD 그림으로 본다.

## 점검자 (`mabi/monitor/`)
태스크는 자기가 아는 순서대로 동작을 요청만 하고, 상황 판단과 대응은 점검자 한곳에서 한다 (2026-10-26 사용자 설계).
태스크마다 if 를 따로 두던 때는 한 곳에서 고친 것(작별 화면·출석)이 다른 태스크에 없어 같은 화면에서 또 막혔다.
- `detect.look()` — 지금 상황 한 단어: 연속 실행 제한 · 로딩 · 캐릭터 선택 · 타이틀 · 나가기 질문 · 출석 · 던전 창 · 구하는 방법 ·
  필요한 아이템 없음 · 확인 · 전달 창 · 결과 보고 · 수락 · 가공 · 재료 전송 · 제작 · 제작 창 · NPC 대화 · 작별 대사 · 연출 · 보상 화면 · 화면 터치 · 쓰러짐 · 메인 · 모름.
  패킷 → CLI → 화면 순. 메인 HUD 가 보이면 창 템플릿을 건너뛴다 (한 번에 2초 → 0.03초).
  `situation.look()` 도 이것을 쓴다.
- `handlers` — 상황별 대응. 묶음이 넷: 어느 일이든(로딩·출석·작별·연출·대화·확인·화면 터치), 메뉴를 다루는 일(수락·결과 보고·전달·던전 창 —
  `Ctx(menus=True)`), 아르바이트 한 건(채집·제작·가공 창 — `Ctx(job=True)`),
  던전·사냥터 보상 화면(추가 루팅 → '다시 하기' 또는 나가기 — `Ctx(reward=True)`). 기다리는 중의 정리(`clear`)는 NPC 메뉴를 누르지 않는다.
- 태스크는 `Ctx` 로 자기 일만 알려 준다: `finish_on`(이 상황이면 그 일은 끝 — 아르바이트의 던전 창, 어비스의 보상 화면),
  `decide`(태스크만 아는 판단 — 모자란 물품이 채집 불가인지), `revive`(쓰러지면 '여기서 부활', 못 하면 끝 'dead'),
  `choose`(NPC 선택지 중 이 낱말이 든 것만 누름 — 요일 던전 임무 게시판·대장간 '수리', 버튼 줄은 `choose_region`.
  이때는 Space 기본 선택지를 누르지 않는다), `leave`(NPC 대화를 마침 — 메뉴는 ESC '대화 종료', 작별 인사 등 대사는 넘기기).
- `check(ctx)` 한 걸음 처리 / `settle()` 처리할 것이 없어질 때까지 / `act(do, expect)` 동작 뒤 기대한 변화가 시간 안에 오나 (안 오면 다시) /
  `clear()` 막는 화면 하나 (`content.clear_blockers` 가 부른다) / `situation.to_main()` 도 점검자로 정리한 뒤 ESC.
- 헛돌기 방지: 같은 처리를 화면(과 패킷 대사 순번)이 그대로인 채 `[monitor] same_limit` 번 하면 멈춤 (`Stuck`).
  모르는 상황이 `unknown_limit` 초 이어지면 메인으로 한 번 돌려 보고, 또 이어지면 멈춤.
- 기록: `logs/acts/날짜.jsonl` 에 상황이 바뀔 때·처리·동작 결과·끝·헛돌기를 한 줄씩 (무엇을 하던 중, 근거 src, 걸린 ms).
- 상황 판정 시험: `tests/fixtures/screens/<상황>/` (폴더 이름이 정답, 캐릭터 이름이 보여 저장소에 안 올림).
  `tools/classify_shots.py --copy` 로 실패 화면을 나눠 담고 틀린 것은 맞는 폴더로 옮긴다. `tests/test_screens.py` 가 확인한다.
- 점검자로 옮긴 것: 아르바이트(전부), 막는 화면 정리(모든 대기), `Bot.to_main`(출석·대화·연출·확인), 접속 단계 정리,
  던전·사냥터·검은 구멍·어비스 안에서 기다리기(`content.watch` — 쓰러짐과 끼어든 창. 안에서는 장면 넘기기를 누르지 않는다),
  던전·사냥터 클리어 뒤(`content.after_clear` — 클리어 화면 터치·연출·보상·퀘스트 확인·대화를 순서 상관없이, 던전 밖 메인이 이어지면 끝),
  어비스 클리어 뒤 보상 화면까지(`abyss.to_reward`), 던전 창 단계 진입, 요일 던전 임무 게시판 선택,
  일일 미션의 진행하기(연금술 창이 열렸나 · 채집하러 미션 창이 닫혔나)와 미션 창으로 돌아오기,
  대장간 수리의 NPC 대화(인사말 넘기기 → '수리' 고르기 → 한마디 넘기기, 마칠 때 `dialogue.leave`),
  접속 직후 창(스텔라 픽·공지 웹 팝업·새 이벤트 창 — 오전 6시 뒤·캐릭터마다 뜰 수도 안 뜰 수도 있어 어느 일에서든 본다.
  `login.settle_first_login` 과 `Bot.dismiss_popups` 도 점검자로).
  미션 카드 '진행하기' 뒤 이동이 12초 안에 시작되지 않으면(`content.started`) 이동 상한까지 기다리지 않고 단계 다시 하기.
- 태스크에 남긴 판단: 어비스의 어디서 시작하나(`abyss.where` — 목록·입장 화면·매칭은 어비스만의 화면), 대장간 수리 창·수리 확인 창
  (`tasks.repair` — 수리에만 있는 창), 접속 직후 버튼 없는 출석 첫 대사 클릭(`login.settle_first_login` — 알아볼 표시가 없다).

## 게임 동작 메모
- 6시 이후 첫 접속 때는 메인 화면 전에 출석 이벤트 대화, '오늘의 스텔라 픽', 공지 웹 팝업이 나올 수 있습니다.
  `login.settle_first_login` 이 순서와 상관없이 처리합니다 (출석부 건너뛰기 / 가운데 카드 → 스텔라 픽 / ESC).
  접속하지 않고 6시를 넘기는 경우(어비스 반복 등)의 출석은 `situation.clear_attendance` 가 넘깁니다.
- 채팅 입력창이 열려 있으면 HUD 의 키 안내(ESC 등)가 사라져 메인 화면 인식이 실패합니다.
- 하루 초기화는 오전 6시. 6시 전은 전날로 칩니다 (`state/<날짜>.json`).
- 접속 전환을 너무 자주 하면 "인증 오류" → 접속 사이 최소 60초.
- ASSIST(H, 우하단 자동 스킬)는 켜져 있어야 하고 봇은 건드리지 않습니다.
- 검은 구멍은 입장 즉시 횟수가 차감되므로 도중에 나가면 안 됩니다.
- 추가 루팅은 요일 던전에만 있고 3회 모두 합니다 (골드 6천/1만2천/1만8천).
- 일요일 요일 던전(2026-10-25 실측): 카드 진행하기가 마을 임무 게시판으로 가서 대화로 빛나는 동굴(골드)·눈부신 저택(보석)·찬란한 유적(촉매) 중 고른다. 고르면 카드 목표가 그 던전으로 바뀌고, 진행하기를 다시 누르면 평일과 같은 던전 창이 열린다. 고를 던전은 숙제 기본값 `[weekday_dungeon] sunday`, 캐릭터별 `[weekday_dungeon.sunday_by_slot]`. 선택 전체 흐름은 단계별로만 확인했고 숙제 실행으로 한 번에 돌려 본 적은 아직 없다.
- 클리어 후 NPC 대화는 모험가 길드 주간 정기 의뢰 조건(심층 3회 / 일반 5회 / 사냥터 5회)을 채웠을 때만 나옵니다.
  봇은 대화가 있으면 넘기고, 없으면 그냥 지나갑니다.
- 사냥터 클리어 화면에서는 CLI 퀘스트 목록이 비어서 나옵니다. 사냥 퀘스트가 3번 연속(약 15초) 없어야 클리어로 봅니다.
- CLI `get_activity` 는 로딩 중 오류를 내고, 지역 이동 중에는 `IsAutoTraveling` 이 false 가 됩니다.
  도착은 장소 이름이나 템플릿으로 판단합니다.
- 캐릭터 선택 화면 카드: 선택된 카드는 노란 테두리·금색 배경에 얼굴 확대 그림. 카드 아래 이름 → 접속 시간 → (대표 캐릭터) → 재화 순.
  스크롤 맨 아래에서 마지막 줄이 화면 아래 어두운 띠에 걸리면 이름 글자가 회색이 된다.
- `bot.to_main()` 은 배고픔 표시가 보이면 음식을 하나 먹는다 (B). 캐릭터 자동 설정으로 선택 화면에 나갈 때도 일어난다.
- CLI `get_my_info` 에는 캐릭터 이름이 없다 (Title = 착용 타이틀, RealmName = 서버).
- 봇은 화면을 캡처해서 인식하므로 다른 창이나 Windows 알림이 게임을 덮으면 실패합니다.
  캡처 전에 게임 창을 앞으로 가져오지만, 알림은 그래도 위에 뜨므로 **방해 금지 모드**를 켜 두세요.

## 작업 큐 (`mabi/workqueue.py`, `gui_app/queue_api.py`)
- 큐의 주인은 파이썬. 화면(web/queue.js)은 'mm:queue' 상태를 그리고 버튼만 보낸다 → 화면을 다시 띄워도 큐는 안 끊김
- 카드 종류: daily(일일 숙제) · abyss(어비스 반복) · goal(제작·채집·가공 목표) · action(버튼 하나 = 명령 하나, 전체 수령)
- 숙제 완료 확인 순서는 패킷 → CLI → 화면 (2026-10-25):
  - 검은 구멍: 맵에 들어갈 때마다 오는 '깬 검은 구멍' 목록에 오늘(6시 뒤) 나온 구멍이 있으면 완료. 없으면 가이드 화면.
    숙제를 시작할 때는 일일 달성 체크를 열지 않고 바로 가기만 연다 (끝냈으면 카드가 없다) — 가이드를 한 번만 연다.
  - 요일 던전: 퀘스트 창 추천 항목이 요일 던전이면 '아직 안 함' (가이드를 열지 않는다). 아니면 가이드 화면.
    던전을 깨면 그걸로 완료 — 숙제가 스스로 확인했으면 실행기가 다시 확인하지 않는다 (가이드를 두 번 열던 것).
  - 은동전·공물·일일 미션: CLI.
- 지도 이동: 패킷으로 다른 마을에 있는 걸 알면 지역 맵 목록을 건드리지 않고 바로 월드맵으로 간다.
- 던전 클리어 뒤 '화면을 터치해 주세요': 패킷이 클리어를 알면 2.5초마다 터치 (예전엔 6초씩 기다렸다).
- 파란 버튼 = 지금 바로 (맨 위에 넣고 돌던 것은 대기로 밀었다가 이어서), '목표' = 맨 아래에 담기
- 일시정지 = 돌던 동작을 잠깐 멈춤. 맨 위 한 장만, 큐는 일시정지 카드에서 선다, 껐다 켜면 대기로 (하던 자리 기록은 유지). 카드 메모에 멈춘 숙제를 적는다 ('[캐릭터] 아르바이트부터 이어서')
- F12 하나로 전체: 돌고 있으면 무엇이든 일시정지(지금 명령도 끊음 — 날개가 들어도 멈춤 우선), 쉬고 있으면 맨 위 일시정지 카드 이어 하기
- Shift+F12 = 지금 카드만 중단 (빼고 다음 카드로), Ctrl+F12 = 전체 중단 (큐를 비움). 숙제의 '게임 조작 시 일시정지'는 Shift·Ctrl 만 누른 것을 조작으로 보지 않는다
- 화면 설정 맞추기는 큐 한 번에 한 번, 할 일이 다 끝나면 되돌림
- 목표 카드가 사람에게 물어야 하면(재료를 직접 구해 와야 함) 'mm:queue-ask' → queue.answer
- 카드 진행 줄(Kind.view — 지금 하는 일·단계·막대)은 파이썬이 만들고 카드와 오버레이가 같이 그린다. 숙제는 runner 의 character·task_start·step·task_end 이벤트로 채운다
- 결과 창 (`mabi/queue_report.py`): 큐를 시작한 뒤 남은 카드(대기·진행·일시정지)가 없어지는 순간 한 번 — 다 끝남·전체 중단·마지막 카드 뺌.
  일시정지는 도는 중으로 친다. 요약 탭(카드별 결과 + 합친 얻은 것·재화·쓴 것) + 카드마다 탭 (숙제는 캐릭터별). 지난 결과는 큐의 '결과' 버튼
  - 얻은 것: CLI get_items(소모품·재료, 가방+보관함 합계) · get_currencies 를 앞뒤로 찍어 뺀다. 숙제는 캐릭터마다(접속 뒤 ~ 그 캐릭터 끝), 나머지는 카드 앞뒤.
    그 사이 사람이 직접 한 것도 섞인다. 장비·의상은 안 나온다
  - 오늘 이미 끝나 건너뛴 캐릭터는 결과에 넣지 않는다
- 작업 큐 오버레이 (`gui_app/queue_overlay.py`, 옵션 → 작업 큐 오버레이, 기본 켜짐): 게임 구석에 진행 상황. 캡처 제외(봇 화면 인식에 안 찍힘)·클릭 통과·포커스 안 가져감.
  배경(반투명 판/없음)·불투명도·글자 크기·구석·여백·다음 카드 수
